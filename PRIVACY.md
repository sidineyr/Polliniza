# Política de privacidade

A extensão Polliniza não utiliza servidor próprio, telemetria ou publicidade. Rascunhos são armazenados localmente pela API de armazenamento do navegador. A versão alfa não solicita nem armazena credenciais de redes sociais. O usuário pode apagar os dados removendo a extensão ou limpando seus dados nas configurações do navegador.


## Aplicativo web

O site possui servidor. Quando OAuth está habilitado, tokens, identificação de contas e registros de publicação ficam em armazenamento compartilhado cifrado, vinculados a uma sessão com expiração de até 12 horas. Reiniciar o aplicativo não remove dados persistidos. Desconectar remove a conta desta sessão; a revogação na plataforma é separada. Sem armazenamento seguro, OAuth fica bloqueado. O responsável pela operação deve informar contato e provedores utilizados antes da abertura pública. Veja a página `/privacidade` e [o guia de sessões](docs/SESSIONS_SECURITY.md).
