# Polliniza Extensão 0.1.0: notas preparadas

[English](extension-v0.1.0.en.md)

Pacote local para Chromium, com editor principal PT-BR/EN, rascunhos locais, adaptação editorial de dez destinos, prévia e publicação assistida. Não conecta contas nem publica por APIs; os conectores OAuth pertencem ao site separado.

Esta preparação conserva a versão e comportamento existentes, completa AGPL-3.0/NOTICE e torna o ZIP determinístico. Artefatos previstos: `polliniza-v0.1.0.zip` e `.sha256`. Firefox e instalação manual final precisam de validação. Não declara publicação em lojas, release GitHub, hospedagem, indexação ou AdSense.
